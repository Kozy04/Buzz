# Nexus AI — Intelligent LLM Gateway & SaaS Framer Template

> A dark-mode Framer template package designed for AI startups, API developer tools, and modern SaaS companies. Includes custom React/Framer components, design tokens, high-converting copy, marketplace submission guides, and a companion launch playbook.

## 🚀 Component & File Guide

### 1. Custom Code Components (`components/`)
* **`CodeSnippetTabs.tsx`**: Multi-language code tab switcher (TypeScript, Python, cURL, Go) with copy-to-clipboard, custom syntax highlights, and property controls.
* **`InteractivePricingCalculator.tsx`**: Interactive slider calculating monthly API costs based on token/request volume with annual discount toggle and custom property controls.

### 2. Design System (`design_tokens.json`)
* Palette: **Nexus Dark Obsidian** (`#08080A`), deep surface fills (`#0E0E12`), electric cyan (`#00F0FF`), and neon purple (`#8B5CF6`).
* Centralized color styles, typography definitions, and glow gradients.

### 3. High-Converting Copy (`landing_page_copy.md`)
* Ready-to-use copy covering Hero section, social proof metrics, 6-card bento grid features, interactive demo windows, pricing tiers, FAQs, and footer.

### 4. Construction Guide (`template_architecture_guide.md`)
* Detailed blueprint for setting up the canvas, Stacks, CMS collections (`Blog`, `Changelog`), hover states, and responsive breakpoints (Desktop: 1280px, Tablet: 810px, Mobile: 390px).

### 5. Monetization & Marketplace Submission (`marketplace_submission_guide.md`)
* Pre-flight checklist to pass Framer's curation review on first submission.
* Step-by-step submission fields, Lemon Squeezy direct sales setup, and Framer Creator Partner Program guide (50% recurring affiliate commissions).

### 6. Bonus Playbook (`bonus_ebook/saas_launch_architecture_playbook.md`)
* *The SaaS Launch & Conversion Architecture Playbook*: Tactical guide on above-the-fold design, pricing psychology, social proof architecture, and launch strategy.
